# Suggested Code availability statement

## During peer review while the repository is private

Custom Python code supporting the findings of this study is available to editors and reviewers during peer review. The code will be released in a public GitHub repository and archived in a DOI-assigned repository before publication.

## After the repository is public and archived

All custom Python code used for Raman data integration, dimensionality reduction, molecular-module analysis, feature attribution, computational molecular ordering, statistical visualization and exploratory differentiation classification is available at GitHub (https://github.com/supervision-xyz/FV-RMH). The version used to generate the results reported in this study is archived on Zenodo at [DOI].

Replace `[DOI]` with the final Zenodo DOI before publication.
