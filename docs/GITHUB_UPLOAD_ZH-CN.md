# GitHub 网页上传步骤

1. 先确认已经修改此前泄露的 GitHub 密码并开启两步验证。
2. 登录 GitHub，点击右上角 `+` → `New repository`。
3. Repository name 填写 `FV-RMH`。
4. 先选择 `Private`，不要勾选自动创建 README（本压缩包已经有 README）。
5. 创建仓库后点击 `uploading an existing file`。
6. 将本压缩包解压后，进入 `FV-RMH` 文件夹，选中其中的全部文件和文件夹拖入网页。
7. Commit message 填写 `Initial code release for FV-RMH`。
8. 点击 `Commit changes`。
9. 检查网页是否出现 `scripts`、`docs`、`README.md`、`requirements.txt`。
10. 整理并验证完毕后，再到 `Settings` → `General` → `Change repository visibility` 改为 `Public`。
